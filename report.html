Report a Problem

If you encounter an issue while using RoamRaven, please let us know so we can investigate and improve the platform.

  • Expected behavior
  • Actual behavior
  • Approximate time of issue

RoamRaven is not an emergency service. Do not submit urgent medical, safety, law enforcement, or emergency requests through this form.

Tip: include city, page or feature, route/stop if relevant, expected vs actual behavior, and approximate time.

Reports are used only for troubleshooting, platform improvement, operational review, and issue resolution.

Please avoid submitting passwords, payment information, medical information, government identifiers, or other sensitive data.
